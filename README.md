# WingDesk 업데이트 배포

WingDesk Windows 프로그램의 실행 파일과 자동 업데이트 안내를 배포합니다.

## 최초 설치

[새 WingDesk 런처 2.0.1 다운로드](https://raw.githubusercontent.com/lookitoone/wingdesk-release/main/launchers/WingDeskLauncher-2.0.1.exe)

[안내 파일 포함 ZIP](https://raw.githubusercontent.com/lookitoone/wingdesk-release/main/launchers/WingDeskLauncher-2.0.1.zip)

WingDeskLauncher-2.0.1.exe를 실행하고 파란색 ‘WingDesk 설치하고 시작’을 누르세요. 기존 런처가 열려 있다면 먼저 종료하세요. 다음부터는 바탕화면의 ‘WingDesk 런처’를 사용합니다. 첫 실행에는 인터넷 연결이 필요합니다. Windows 10/11 64비트와 .NET Framework 4.7.2 이상을 사용하며 별도 Python 설치나 관리자 권한은 필요하지 않습니다.

새 런처는 일반 .NET Windows 프로그램이며 숨겨진 PowerShell이나 자체 압축 해제 EXE를 사용하지 않습니다. python.org의 공식 Python을 내려받아 고정 SHA-256·파일별 해시·Windows 배포자 서명을 확인한 뒤 실행합니다. 현재 상품 관리 버전은 1.6.7입니다. 기존 상품·계정 저장 위치를 유지합니다.

이 런처는 아직 WingDesk 배포자 인증서로 서명되지 않았습니다. Chrome·Defender 미탐지를 보장하지 않으며 Windows 실기기와 실제 브라우저 탐지는 미검증입니다. 보안 경고가 계속되면 강제로 실행하거나 보안 기능을 끄지 말고 정확한 경고·탐지 이름을 배포자에게 전달하세요. 배포자는 정식 코드 서명과 공급업체의 탐지 재검토를 진행해야 합니다.

[런처 실행 파일 SHA-256](https://raw.githubusercontent.com/lookitoone/wingdesk-release/main/launchers/WingDeskLauncher-2.0.1.sha256.txt)

## 이후 업데이트

새 런처 2.0.1은 launcher-app.json에서 새 상품 관리 버전을 확인합니다. ‘업데이트하고 실행’을 누르면 일반 앱 파일 묶음을 검사·설치하고 공식 Python으로 실행합니다. 기존 자체 압축 해제 EXE는 내려받거나 실행하지 않습니다. 1.6.4는 기존 공개 앱에 상품 정보 자동 채움과 기본 등록 프리셋을 추가했습니다. 파일별 해시 목록으로 앱 묶음을 검증합니다.

기존 런처는 update.json에서 새 버전을 확인합니다. ‘업데이트하고 실행’을 누르면 다운로드·검사·설치 후 새 버전을 엽니다. 상품 등록·수집·주문 작업 중에는 먼저 작업을 마치라는 안내를 표시합니다. 상품·계정 데이터는 사용자 PC에 유지합니다.

1.5.8 런처는 1.6.3으로 업데이트할 수 있습니다. 이전 런처에서 코드 1 종료 오류가 나면 최신 ZIP의 WingDeskLauncher.exe를 사용하세요.

## 런처 2.0.1 압축 해제 오류 수정

2.0.0에서 파일을 내려받은 후 압축 해제 단계에 System.String.TrimEnd(Char) 메서드 오류가 발생하던 문제를 수정했습니다. 모든 TrimEnd 호출을 Windows .NET Framework가 지원하는 Char[] 형태로 바꾸고 Microsoft의 공식 .NET Framework 4.7.2 참조 라이브러리로 다시 빌드했습니다. 이전 바이너리의 잘못된 호출과 수정본의 호환 호출을 실제 메타데이터에서 대조했습니다. 빌드 단계에서도 Mono 구현 DLL을 대상으로 지정하면 거부합니다.

열려 있는 2.0.0 런처를 모두 닫고 새 WingDeskLauncher-2.0.1.exe를 실행하세요. 기존 상품 관리 버전 1.6.3과 데이터 저장 위치는 유지합니다. 무결성 검사 47개와 운영 서버 다운로드·압축 해제·설치·해시 오류 시 기존 설치 보존 검증을 통과했습니다. Windows 실기기의 전체 실행은 여전히 별도 확인이 필요합니다.

## 1.6.7 구성 수량 표시 · 등록 제외 분류

상품 옵션에 있던 구성 수량과 단위를 상품 상세의 공통 칸에도 표시합니다. 같은 구성은 자동으로 채우고 서로 다른 구성은 옵션별로 안내합니다. 공통 수량 수정은 같은 구성 옵션의 실제 등록 내용에도 반영합니다.

상품관리에서 ‘선택 상품 등록 제외’를 누르면 별도 탭에 보관합니다. 상품 정보와 기존 실패 기록은 유지하며 등록 대상으로 되돌릴 수 있습니다. 제외 상품의 대기 예약은 해제하고 직접·예약 신규 등록을 차단합니다. 복원 후 예약은 다시 추가하세요. 기존 쿠팡 상품은 판매 중지하거나 삭제하지 않습니다.

## 1.6.6 등록 준비 자동화 · 고시 종류·반품비·검색어

상품관리에서 상품을 선택한 뒤 쿠팡 등록을 열면 공급사 정보로 품명·제조사·수량·고시·검색어를 먼저 채우고 준비 상태를 보여줍니다. 등록 내용 확인 후에는 배경의 준비 상태도 갱신합니다.

상품고시 목록 첫 번째 항목을 선택하던 방식을 수정했습니다. 기본은 카테고리에서 허용하는 기타 재화를 우선 사용하며, 설정에서 공급사에 명시된 종류 우선으로 변경할 수 있습니다. 과거 자동 선택값은 보정하고 직접 입력한 종류와 내용은 유지합니다. 품명·제조사·원산지는 확인되는 실제 값을 먼저 사용하며 없는 고시 값은 상세페이지 참조로 채웁니다.

공급사 정보로 확인되는 색상계열·실리콘 종류·투명 여부 등 일부 선택 검색필터를 채웁니다. 등록 화면에서 반품 배송비를 구매자 배송비와 별도로 저장할 수 있습니다. 저장값이 없으면 기본 4,000원이며 기존 저장 금액은 유지합니다. 검색어는 상품명·공급사 검색어에서 만들고, 복사한 목록을 붙여넣어 선택 상품에 저장할 수 있습니다.

[1.6.6 패치노트](notes/WingDesk-1.6.6.md) · [현재 패치노트](PATCHNOTES.md)

Python 386개, JavaScript 4종, Chromium 전체 모의 흐름과 1,000개 등록 검증을 통과했습니다. 쿠팡 자동완성 실시간 조회와 이미지 OCR, 기존 원격 상품의 일괄 수정은 포함하지 않습니다. 실제 판매자 API와 Windows 실기기는 별도 확인이 필요합니다.

## 1.6.5 등록 거절 사유 표시 수정

쿠팡이 상품 등록을 거절했을 때 실제 message·details·errorItems가 일반 인터넷 연결 문구로 바뀌어 표시되던 문제를 수정했습니다. 등록 현황에서 문제 옵션·속성과 상세 사유를 확인할 수 있습니다. 성공한 상품의 빈 배열 표시도 읽기 쉬운 안내로 바꿨습니다.

실제 응답이 불분명하면 남은 전송을 중단하며 자동으로 다시 보내지 않습니다. 오류와 상품 ID가 함께 오면 등록 여부를 확인하기 전 재전송하지 못하도록 보호합니다. 1.6.4에서 원문이 남지 않은 실패 기록의 실제 원인은 복원할 수 없습니다. 이 패치는 원인 표시를 수정하며 특정 실제 상품의 등록 오류가 해결되었다고 보장하지 않습니다.

[1.6.5 패치노트](notes/WingDesk-1.6.5.md) · [현재 패치노트](PATCHNOTES.md)

Python 364개, JavaScript 4종, Chromium 모의 API 전체 흐름과 기존 1,000개 등록 검증을 통과했습니다. 실제 판매자 상품 생성과 Windows 실기기는 별도 확인이 필요합니다. 앞으로 앱 업데이트마다 패치노트와 업데이트 방법을 함께 제공합니다.

## 1.6.4 상품 정보 자동 채움 · 기본 등록 프리셋

상품관리에서 상품을 선택하고 ‘선택 상품 정보 자동 채우기’를 누르세요. 상품명·공급사 옵션·상세설명 텍스트에서 구성 수량과 단위(개·세트·팩·켤레 등), 색상과 사이즈를 연결합니다. 재고와 박스 수량을 구성 수량으로 사용하지 않습니다. 이미지 OCR은 포함하지 않습니다.

기본 등록 프리셋은 인증·신고 대상 아님, 병행수입 아님, 전체 연령, 인당 최대구매수량 설정 안 함, 판매기간 설정 안 함입니다. ‘기본 등록 프리셋 설정’에서 저장만 하거나 선택 상품에 일괄 적용할 수 있고 다음 등록 준비에도 사용합니다. 쿠팡 API에 판매 시작·종료일이 필요하므로 기간 제한 없음은 종료일 2099-12-31로 전송합니다.

상품고시의 비어 있는 항목은 상세페이지 참조로 채웁니다. 인증 비대상 기본값은 카테고리에서 지원하고 필수 인증이 없는 상품에 적용합니다. 실제 공급사/입력 인증번호는 보존합니다. 추천·선택 인증을 모두 요구하지 않으며 진짜 필수 인증번호나 서류만 별도로 확인합니다.

수량 정보가 없을 때 기본 1개(세트 상품은 1세트)를 사용하며 수량과 단위를 변경하거나 끌 수 있습니다. 수량이 모호하면 확인 대상으로 남깁니다. 자동 채움과 프리셋 저장은 상품을 전송하지 않습니다. 실제 등록 내용 확인과 별도 전송 확인은 유지합니다.

Python 352개 검사, JavaScript 4종, Chromium 전체 흐름과 프리셋 저장·복원·200개 자동 채움·기존 1,000개 모의 등록을 통과했습니다. Windows 실기기와 실제 판매자 API는 별도 확인이 필요합니다.

## 1.6.3 빠진 정보 안내와 단계별 입력

등록에 필요한 정보가 빠져 있으면 상품 옆에 내용을 바로 표시합니다. 등록 검사 후에는 아직 전송하지 않았다는 안내와 필요한 정보별 상품 수, 첫 상품 입력 버튼을 보여 줍니다.

‘빠진 정보 입력하기’를 누르면 필요한 칸만 큰 글씨로 안내합니다. ‘입력한 내용 저장하고 다음으로’를 눌러 필수 특징·종류와 재고·상품 안내정보·인증 등을 차례로 입력하고 다음 상품으로 넘어갑니다. 빈칸은 같은 화면에서 안내하며 입력한 내용은 단계마다 저장합니다. 인증 대상 여부·제조사·재고 등의 실제 사실은 자동으로 선택하지 않습니다. 모든 입력이 끝난 뒤 등록 내용을 따로 확인해야 쿠팡에 전송합니다.

## 1.6.2 화면 정리와 등록 현황

상품 관리와 쿠팡 등록 화면에서 단일상품 / 옵션형·N개를 배지로 구분합니다. 바로 등록과 시간 예약은 상단 작업 영역에서 선택하고, 검사·내보내기·삭제·공통 입력은 도구 메뉴에서 엽니다. 장식 배너와 반복 안내를 줄였습니다.

등록 현황에 진행률·현재 처리 상품·성공/실패/확인 필요·남은 수량을 표시합니다. 모든 화면에서 1.5초마다 작업 상태를 확인하며 상단 진행 표시로 현황을 열 수 있습니다. 결과 필터, 50개 단위 페이지와 이전 작업 조회를 지원합니다. 실제 전송 성공과 쿠팡 심사·승인은 별도로 확인하세요.

## 수량 지정·전체 선택·바로 등록과 시간 예약

등록 수량을 1~1,000개로 직접 입력하거나 검색 결과 전체를 페이지를 넘어 선택할 수 있습니다. 200개·1,000개도 내용 확인 후 하나의 작업으로 순차 전송하며 진행률·상품별 결과·작업 중단을 제공합니다.

자동 상품 관리의 ‘즉시·예약 등록’에서 바로 등록 준비 또는 한국 시간 기준 날짜·시간 예약을 선택하세요. 예약 목록에 예정 시각·등록 방식·보류 사유를 표시하며 시간 변경·예약 해제를 지원합니다. PC와 WingDesk가 실행 중일 때 동작하며, 꺼져 있던 동안 지난 예약은 다음 실행 시 처리합니다. 기존 매일 예약 등록 수량도 1~1,000개로 지정할 수 있습니다.

## 실제 상품 등록

상품 관리에서 상품을 선택하고 ‘쿠팡 등록’ 탭을 여세요. 카테고리 추천과 상품별 필수정보 보완, 같은 카테고리 상품의 공통 필수정보 입력을 지원합니다.

쿠팡 연결과 출고지·반품지 설정을 마친 뒤 누락 정보를 보완하세요. ‘판매 승인 요청’ 또는 ‘임시저장’을 선택하고 등록 내용을 확인한 뒤 실제 전송합니다. 반환된 상품 ID와 현재 상태는 등록 작업 내역에서 확인합니다. 테스트 검사는 실제 상품을 생성하지 않습니다.

개발용 전체 소스 ZIP이나 사용자 DB·계정 파일은 이 저장소에 업로드하지 않습니다. 새 런처의 packages/WingDesk-app-버전.zip에는 실행에 필요한 일반 Python·라이브러리·화면 파일과 BUNDLE-MANIFEST.json을 넣습니다. 실행 EXE 자체에는 기존 구조에 따라 Python 소스가 내장되어 있습니다.

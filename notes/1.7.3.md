# WingDesk 1.7.3 패치노트

배포일: 2026년 11월 4일

- 오너클랜 계정을 처음 연결할 때 같은 Windows 사용자에게 암호화 저장하는 옵션을 기본 선택합니다. 저장된 계정은 업데이트나 재실행 후에도 유지되며 상품 수집 시 다시 인증합니다.
- 계정 연결 화면에 이 PC 저장 여부를 표시하고, 일시 사용을 선택하면 다음 실행에 계정이 남지 않는다는 설명을 추가했습니다. 원하면 저장을 해제할 수 있습니다.
- 이전에 암호화 저장하지 않고 종료해 사라진 비밀번호는 복구할 수 없어 한 번 다시 입력해야 합니다. 저장된 계정은 그대로 유지합니다.

Windows 암호화 방식으로 1.7.2 저장 계정의 1.7.3 재시작 복원, 모의 자동 인증과 저장 해제, 연결 화면의 기본값과 표시를 확인했습니다. 실제 오너클랜 서버 연결은 검증하지 않았습니다.

런처 2.0.1에서 새 버전을 다시 확인한 후 업데이트하세요.

# WingDesk 1.7.0 패치노트

배포일: 2026년 11월 3일 · AI 상세페이지 체험 기능

## 추가한 기능

- 왼쪽 메뉴에 ‘AI 상세페이지’를 추가했습니다. 상품 목록에서 한 개를 선택하고 상품 도구 → AI 상세페이지 만들기로도 시작할 수 있습니다.
- 상품명·설명·사진 최대 3장으로 상품을 분석하고 소개 문구와 연출 이미지를 만듭니다. 깔끔한·따뜻한·고급스러운 분위기, 설명 길이, 생성 이미지 1~3장을 선택합니다.
- Gemini 2.5 Flash-Lite로 상품을 분석하고, Cloudflare의 FLUX.2 klein 4B로 사진을 참고한 연출 이미지를 생성합니다. 일반 사무용 노트북에서도 외부 서버에서 처리합니다.
- 문구를 고친 뒤 860×1600 PNG 상세페이지를 완성합니다. 한글 글꼴을 함께 제공하며, PNG·미리보기 HTML·문구 TXT가 포함된 ZIP으로 내려받을 수 있습니다.
- 초안과 생성 중 받은 이미지는 PC에 보관됩니다. 생성 중 화면을 이동했다 돌아와도 진행 상황을 확인할 수 있습니다. 실패·시간 초과·무료 한도 오류는 자동으로 재생성하지 않습니다.
- 쿠팡 등록용 이미지 주소 준비를 누르면 연결한 Cloudflare Free 계정에 Workers·KV 이미지 보관소를 마련하고 완성 이미지를 공개합니다. 이미지가 실제로 열리는지 확인한 뒤 상품에 적용합니다. AI 키는 공개 서버에 넣지 않습니다.
- 상품 적용은 기존 등록 내용 확인·전송 절차와 분리되어 있습니다. 기본적으로 기존 공급사 상세설명을 아래에 유지하며, 전송 전에는 원래 상세설명으로 되돌릴 수 있습니다. 적용 후 직접 수정한 내용은 자동 복원으로 덮어쓰지 않습니다.
- 1.6.8의 등록 대기·쿠팡 등록됨 메모 기능과 기존 상품·계정 저장 위치를 유지합니다.

## 처음 한 번 필요한 설정

AI 상세페이지 → AI 연결 설정에서 Gemini 무료 프로젝트의 API 키, Cloudflare Account ID·API 토큰을 입력하세요. 채팅에 키를 보내지 마세요.

- Gemini: 결제가 연결되지 않은 Free 프로젝트를 사용하세요. API 키만으로는 앱이 프로젝트의 결제 상태를 확인할 수 없습니다. 유료 프로젝트의 키를 넣으면 제공업체에서 요금이 발생할 수 있습니다. 무료 서비스에 보낸 상품 사진·문구는 Google의 서비스 개선에 사용될 수 있습니다.
- Cloudflare: Workers Free 계정과 무료 workers.dev 주소를 사용하세요. 토큰에는 Workers AI 조회·편집, Workers Scripts 편집, Workers KV Storage 편집, Account Settings 조회, Billing 조회 권한이 필요합니다. Workers 유료 구독이 조회되거나 구독 조회에 실패하면 생성을 중단합니다.
- 키는 실행 중 메모리에만 보관하거나, 사용자가 선택하면 같은 Windows 사용자에게 DPAPI로 암호화하여 저장합니다. 쿠팡 키와 별도로 관리합니다.
- 외부 서비스 계정·프로젝트를 자동으로 가입하거나 유료 전환하지 않습니다. 연결 설정의 단계별 링크를 이용하세요.

## 무료 범위와 확인된 제한

- 무료 한도 내 이용을 목표로 한 체험 기능이며 무제한 무료가 아닙니다. 계정 요금제와 외부 서비스 정책이 적용됩니다.
- WingDesk는 이 PC의 하루 요청 상한을 분석 20회·이미지 60장으로 제한하고 보수적인 이미지 연산량 상한도 적용합니다. 실패 요청도 포함합니다. PC 내 상한은 UTC 자정(한국 시간 오전 9시)에 초기화되며, 제공업체의 실제 한도·다른 앱의 사용량과는 별개입니다.
- 외부 한도에 먼저 도달할 수 있습니다. 한도 초과·타임아웃·권한 오류 시 중단하며 자동 재시도·다른 유료 모델 전환·다음 날 자동 재개는 하지 않습니다.
- 이미지 보관소에도 Cloudflare Free의 저장·읽기·쓰기·요청 한도가 있습니다. 한도에 도달하면 공개 이미지가 일시적으로 열리지 않을 수 있습니다. 공개한 이미지는 기존 상품을 보호하기 위해 자동으로 지우지 않습니다.
- AI가 상품의 형태·색상·구성이나 문구를 잘못 만들 수 있습니다. 실제 상품과 일치하는지 검토하세요. 인증·고시·재고·가격은 AI가 변경하지 않습니다. 완성 페이지에는 AI 연출 이미지 표시가 들어갑니다.
- 사진은 최대 512px로 줄여 AI에 보내므로 작은 로고·세부 무늬가 달라질 수 있습니다. 상품별 품질과 영상과 동등한 결과는 아직 검증하지 않았습니다.
- 이미 쿠팡에 전송한 상품은 WingDesk에서 덮어쓰지 않습니다. 완성 파일을 내려받아 Wing에서 수정하세요. 생성 후 상품 정보가 달라지면 새 초안에서 다시 시작해야 합니다.
- 사용자 자격증명이 없어 실제 AI 생성·무료 요금제 판정·Workers/KV 생성·공개 CDN 전파·쿠팡 실등록은 검증하지 못했습니다. 모의 응답과 실제 연동을 구분합니다.

## 검증

Python 자동 검사 432개와 JavaScript 검사 5종을 통과했습니다. 실제 PNG 합성·한글 글꼴 로딩도 확인했습니다. 새 검사는 키 비노출, 무료 동의·유료 Workers 차단, 한도·취소·재시도 금지, 중단 후 복구, 초안 변경 충돌, 공개 이미지 확인, 상품 적용·원본 복원, 다른 초안 이미지 차단과 로컬 주소 접근 차단을 다룹니다. 최종 통과 개수는 배포 매니페스트에 기록합니다.

클라우드 브라우저가 로컬 시험 서버에 연결하지 못해 실제 브라우저 조작은 완료하지 못했습니다. Windows 실기기도 미검증입니다. 화면 로직과 PNG 합성 검사를 실제 브라우저 검증으로 표시하지 않습니다.

## 업데이트

WingDesk 런처 2.0.1 → 새 버전 다시 확인 → 1.7.0 업데이트하고 실행.

2.0.1보다 오래된 런처는 먼저 최신 런처로 교체하세요. [WingDesk 런처 2.0.1 다운로드](https://raw.githubusercontent.com/lookitoone/wingdesk-release/main/launchers/WingDeskLauncher-2.0.1.exe). 구형 update.json은 EXE 패키지 전용이므로 1.6.3 호환 배포를 유지하며, 1.7.0 앱 ZIP은 런처 2.0.1의 launcher-app.json으로 제공합니다.

AI 기능을 사용하지 않으면 새 AI 계정이나 키를 연결할 필요가 없습니다. 처음에는 생성 이미지 1장으로 상품 모습과 문구가 잘 유지되는지 확인하세요.

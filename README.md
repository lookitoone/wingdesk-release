# WingDesk 업데이트 배포

WingDesk Windows 실행 파일과 자동 업데이트 안내를 배포하는 저장소입니다.

- [최신 버전 다운로드](https://github.com/lookitoone/wingdesk-release/releases/latest)
- [런처 업데이트 안내](https://github.com/lookitoone/wingdesk-release/releases/latest/download/update.json)

최초 한 번 실행 ZIP의 WingDeskLauncher.exe를 실행한 뒤 같은 바탕화면 런처를 사용합니다. 새 버전은 ‘업데이트하고 실행’으로 설치합니다. 상품·계정 데이터는 사용자 PC에 보관됩니다.

배포 계획과 검사된 실행 ZIP을 main 브랜치에 반영하면 GitHub Actions가 두 파일을 초안 릴리스에 올린 뒤 최신 릴리스로 발행합니다. Windows 실기기 검증 여부는 각 릴리스 안내를 확인하세요.

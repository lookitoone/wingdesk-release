# WingDesk 1.6.7 패치노트
배포일: 2026년 10월 20일

## 구성 수량·단위 표시 보완
- 옵션에 수량이 자동 입력됐는데 상품 상세의 공통 수량·단위 칸은 비어 보이던 문제를 수정했습니다.
- 판매 가능한 옵션들의 구성이 모두 같으면 위쪽 두 칸에도 수량과 단위를 표시합니다. 기존에 저장한 상품에도 적용됩니다.
- 옵션마다 구성이 다르면 공통값으로 억지로 합치지 않고 ‘옵션마다 구성이 다릅니다’라고 안내합니다.
- 같은 구성을 가진 상품의 공통 수량·단위를 수정하면 옵션의 구성 수량과 수량 속성도 함께 맞춥니다. 서로 다른 구성의 옵션은 개별 값을 유지합니다.
- 설명을 ‘한 번 구매하면 받는 수량’, ‘수량의 단위’로 바꾸고 예시를 추가했습니다. 예를 들어 3개 묶음은 수량 3·단위 개이며, 판매 재고 수량은 별도입니다.

## 등록 제외·복원
- 상품관리에서 상품을 선택하고 ‘선택 상품 등록 제외’를 누르면 등록하지 않을 상품으로 보관합니다.
- ‘등록 제외’ 탭에서 모아 보고 ‘등록 대상으로 되돌리기’로 복원할 수 있습니다. 상품 정보와 기존 실패 기록은 유지합니다.
- 제외한 상품의 기존 예약은 해제합니다. 되돌려도 예전 예약을 자동으로 복구하지 않으며 필요할 때 다시 예약하세요.
- 등록 준비 목록과 예약 상품 선택에서 제외하고, 직접 전송·예약 전송 경로에서도 차단합니다.
- 전송 중이거나 등록 결과 확인이 필요한 상품은 먼저 결과를 확인해야 분류할 수 있습니다.
- 이 분류는 신규 등록 대상을 관리합니다. 이미 쿠팡에서 판매 중인 상품을 자동으로 판매 중지하거나 삭제하지 않습니다.

## 업데이트
Launcher 2.0.1 → 새 버전 다시 확인 → 업데이트하고 실행

## 검증
Python 자동 검사 404개와 JavaScript 검사 4종을 통과했습니다. Chromium에서 구성 수량 표시·수정, 등록 제외·복원, 예약 해제 및 기존 1,000개 모의 등록 흐름을 확인합니다. 실제 판매자 API 전송과 Windows 실기기 실행은 별도 확인이 필요합니다.

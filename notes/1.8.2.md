# WingDesk 1.8.2 · 대량 수집 정리

배포일: 2026년 11월 24일

- 상품 가져오기에서 ‘보관함·수집 내역 모두 비우기’를 선택할 수 있습니다. 현재 오너클랜 계정의 수집 내역과 상품코드 보관함을 확인 후 비웁니다. 상품 목록과 쿠팡에 등록한 상품은 삭제하지 않습니다.
- 비우기 전에 이 PC의 WingDesk 데이터 폴더에 복구용 데이터 사본을 만듭니다. 사본을 만들 수 없거나 확인한 내역이 바뀌면 삭제하지 않습니다. 수집 중인 경우 먼저 수집을 중단하고 완료를 기다리세요.
- 상품 수집 진행 중에는 전체 수집 내역을 반복해서 읽는 대신 진행률만 확인합니다. 목록은 한 번에 처리하는 데이터 양을 줄였고, 선택 상품 추가와 상세 조회도 필요한 상품만 불러옵니다.
- 전체 정리 후에는 새로운 코드 파일을 읽어 상품 정보를 가져올 수 있습니다. 코드 보관함은 비워지므로 필요한 코드 파일은 따로 보관해 주세요.

가상 상품 16,000건의 정리·복구 사본·기존 상품 보호와 정리 후 새 상품 900건의 목록 추가를 확인했습니다. 실제 오너클랜·쿠팡 계정으로 상품 등록은 검증하지 않았습니다.

런처 2.0.1에서 새 버전을 다시 확인한 후 업데이트하세요.

# WingDesk 1.6.6 패치노트
배포일: 2026년 10월 20일

## 상품 선택 후 먼저 자동 입력
- 상품관리에서 선택한 뒤 쿠팡 등록 화면을 열면 상품명·제조사·수량·상품고시·검색어를 먼저 채우고 준비 상태를 표시합니다.
- 쿠팡 필수항목을 아직 가져오지 않은 분류는 조회한 뒤 준비합니다. 입력을 마쳤는데 뒤쪽 목록에 계속 누락으로 보이던 표시도 갱신합니다.
- 구성 수량과 총 수량을 공급사 옵션·상품명·고시에서 찾습니다. 공급사 재고를 판매 구성 개수로 사용하지 않습니다.

## 상품정보제공고시 종류 개선
- 고시 목록 첫 번째 종류를 임의로 선택하던 방식을 수정했습니다.
- 기본은 쿠팡에서 허용하는 ‘기타 재화’를 우선 선택합니다. 설정에서 공급사에 명시된 고시 종류를 우선하도록 바꿀 수 있습니다.
- 이전 버전에서 자동 선택된 잘못된 고시 종류는 등록 전 자동 입력에서 보정합니다. 직접 선택·입력한 종류와 내용은 보존합니다.
- 품명·제조사·원산지는 확인되는 실제 값으로 채우고, 없는 고시 항목은 상세페이지 참조로 채웁니다.
- 해당 카테고리가 기타 재화를 지원하지 않고 공급사 종류도 확인할 수 없으면 사용자 확인 대상으로 남깁니다.

## 검색필터 자동 입력
- 공급사 옵션·고시·상품명·상세설명 텍스트에서 확인되는 색상계열, 실리콘 종류, 투명 여부 등 일부 검색필터를 채웁니다.
- 쿠팡에서 허용하는 항목과 값만 사용합니다. 확인되지 않는 선택 항목은 빈칸으로 두며 등록을 막지 않습니다.

## 반품·교환 배송비 설정
- 쿠팡 등록 화면에 편도 반품 배송비 입력·저장 칸을 추가했습니다.
- 구매자 배송비 3,000원과 별도로 반품비 4,000원을 저장할 수 있습니다. 저장한 기존 반품비는 유지하며, 저장값이 없는 경우 기본 4,000원을 보여줍니다.
- 최종 등록 내용에도 반품비를 표시합니다. 확인 후 배송비가 바뀌면 다시 확인해야 전송할 수 있습니다.

## 검색어 자동 생성·일괄 붙여넣기
- 비어 있는 검색어를 공급사 검색어와 상품명에 실제 포함된 단어로 만듭니다.
- 복사한 검색어를 쉼표·줄바꿈으로 붙여넣어 선택 상품에 저장할 수 있습니다. 기존 목록에 추가하거나 교체할 수 있습니다.
- 중복을 제거하며 최대 20개, 검색어 한 개당 20자까지 입력합니다. 상품 상세 화면과 CSV의 검색어 열에서도 수정할 수 있습니다.
- 등록 내용 확인 화면에서 고시 종류와 검색어를 확인할 수 있습니다.

## 사용 방법
Launcher 2.0.1 → 새 버전 다시 확인 → 업데이트하고 실행
상품관리에서 상품 선택 → 쿠팡 등록 → 자동 입력된 정보 확인 → 필요하면 반품비·검색어 저장 → 등록 내용 확인 → 실제 전송

## 확인할 점
쿠팡 자동완성 목록의 실시간 조회와 이미지 속 글자 OCR은 포함하지 않습니다. 검색어를 20개까지 억지로 늘리거나 상품과 무관한 추천어를 자동으로 넣지 않습니다. 이미 쿠팡에 등록된 상품의 정보는 이번 자동 입력으로 변경하지 않습니다. 실제 판매자 API 등록과 Windows 실기기 실행은 별도 확인이 필요합니다.
